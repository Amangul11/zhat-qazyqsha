## 📚 ЖПТ Қазақша - Тарихи сұрақ жауап чаты

Қазақ тарихына байланысты сұрақтарға деректер мен фактілермен жауап беретін ЖПТ (жиынтықталған ақпарат өндіргіш).

### ✨ Мүмкіндіктері

- 🔍 **Тарихи оқиғаларды іздеу** - Қазақ тарихындағы оқиғаларды табу
- 📖 **Деректер базасы** - 50+ тарихи оқиғалар
- 📚 **Дереккөздер** - Әр жауапқа ғылыми дереккөзі
- 📊 **Сенімділік деңгейі** - Ақпарат сенімділігін көрсету
- 🌍 **Қазақша интерфейсі** - Толық қазақша қолдау

### 🛠️ Құрылымы

```
zhat-qazyqsha/
├── main.py              # FastAPI серверсі
├── frontend.py          # Streamlit интерфейсі
├── requirements.txt     # Python ынамдықтарын
├── data/
│   └── history.json     # Тарихи деректер
└── README.md           # Құжаттама
```

### 🚀 Орындау

#### 1. Репозиторийді клондаңыз

```bash
git clone https://github.com/Amangul11/zhat-qazyqsha.git
cd zhat-qazyqsha
```

#### 2. Виртуалды ортасын құрыңыз

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

#### 3. Ынамдықтарды орнатыңыз

```bash
pip install -r requirements.txt
```

#### 4. FastAPI серверін қосыңыз

```bash
python main.py
```

Сервис `http://localhost:8000` адресінде орындалады.

#### 5. Streamlit интерфейсін қосыңыз (басқа терминалда)

```bash
streamlit run frontend.py
```

Интерфейс `http://localhost:8501` адресінде ашылады.

### 📡 API Маршруттарды

#### 1. Сұрақ сөйлеу

```bash
POST /ask

{
  "question": "Қазақ хандығы қашан құрылды?"
}
```

**Жауап:**
```json
{
  "question": "Қазақ хандығы қашан құрылды?",
  "answer": "...",
  "sources": ["Дереккөз 1", "Дереккөз 2"],
  "confidence": "Жоғары",
  "related_events": [1, 2, 3]
}
```

#### 2. Барлық оқиғаларды алу

```bash
GET /events?skip=0&limit=10
```

#### 3. Іздеу

```bash
GET /search?q=Керей
```

#### 4. Сервис сынағы

```bash
GET /health
```

### 📖 Жазбаланған оқиғалар

1. **Қазақ хандығының құрылуы** (1465-1466)
   - Керей мен Жәнібек сұлтандар құрады
   - Дереккөз: Мұхаммед Хайдар Дулатидің "Тарих-и Рашиди"

2. **Ислам дінінің келуі** (VIII-IX ғасырлар)
   - Орта Азияға ислам дінінің өндіктегіліктері
   - Дереккөз: Табари "Тарих ар-русул ва-л-мулук"

3. **Әйтеке би және Қайым би** (XVI-XVII ғасырлар)
   - Қазақ хандығындағы өндіктеген өндіктегіліктер
   - Дереккөз: Қазақ ауызды аңыз-құлыптары

4. **Түстік Қазақстанға Ресейдің өндіктегіліктігі** (XVIII-XIX ғасырлар)
   - Ресейдің Қазақстанға өндіктегіліктігі
   - Дереккөз: Ресей мемлекеттік архивтері

5. **Советтік Қазақстан** (1936)
   - Қазақ ССР ресімі құрылуы
   - Дереккөз: КСРО мемлекеттік құжаттары

### 📝 Новых оқиғалар қосу

1. `data/history.json` файлын өтеңіз
2. Жаңа оқиғаны `events` массивіне қосыңыз
3. Файлды сақтаңыз
4. Серверін өрнегендіңіз

### 🧪 Сынақы

```bash
# Барлық оқиғалар
curl http://localhost:8000/events

# Іздеу
curl http://localhost:8000/search?q=Керей

# Сұрақ сөйлеу
curl -X POST http://localhost:8000/ask \
  -H "Content-Type: application/json" \
  -d '{"question": "Қазақ хандығы қашан құрылды?"}'
```
